All kernel releases are cryptographically signed using OpenPGP-compliant signatures. Everyone is strongly encouraged to verify the integrity of downloaded kernel releases by verifying the corresponding signatures. Basic concepts Every kernel release comes with a cryptographic signature from the person making the release.
